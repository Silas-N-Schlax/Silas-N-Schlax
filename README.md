### About

I'm a developer at [RoleModel Software](https://rolemodelsoftware.com), working primarily in **JavaScript** and **Ruby**. I build full-stack web applications with Ruby on Rails and React, with a focus on clean, well-tested code and a craftsmanship-first approach to software.

I trained through The Odin Project and RoleModel's Software Craftsmanship Academy, and I continue to build and ship production sites for small businesses and nonprofits.
